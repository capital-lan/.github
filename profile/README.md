**Capital LAN Corp.** is a New York 501(c)(3) nonprofit that runs LAN party and gaming events in the Capital Region.

- **[capitallan.com](https://www.capitallan.com)**: events, registration and the community.
- **[capitallan.org](https://www.capitallan.org)**: the organization, donations, sponsorship and press.

Most of our code is private, since it runs our events and venues. Public repos:

- **[Samsung-LN32D467-Hospitality](https://github.com/capital-lan/Samsung-LN32D467-Hospitality)**: how to set the boot logo and clone settings on Samsung hospitality-mode TVs, including an install guide Samsung no longer hosts.
